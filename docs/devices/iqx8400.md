# IQX8400 Rev1.1 接入

板卡安装、接口、物理通道名和时钟规格见 [IQX8400 中英文硬件手册入口](https://github.com/lichen813-gif/iqx8400-specs)。软件步骤见 [C API 使用说明](../c-api.md)、[Python 开发指南](../python-guide.md) 和 [兼容矩阵](../compatibility.md)。

1. 获取与板卡修订、FPGA 镜像及主机系统匹配的 PCIe 驱动。按 [Windows 驱动安装](../c-api.md#231-准备编译工具和驱动) 或 [Linux 驱动安装](../c-api.md#241-准备工具解压源码与核对设备) 操作，记录驱动版本并核对设备绑定。
2. 确认该交付组合使用 `pciex:0` 还是 `pcies:`。`pciex:0` 对应 SDK 枚举的第一个 PCIEX 设备。支持拆分的 4T4R Bypass 镜像可以用 `pcies:0.0`、`pcies:0.1` 打开两个独立句柄，每个句柄的 `0x3` 对应其本地两路。使用 [双句柄测试](../c-api.md#431-pcies-双句柄测试) 的命令，并用已知信号核对物理接口与掩码的映射。
3. 先使用通用指南的首帧接收程序验证本地第 1 路。按机型说明配置采样率、中心频率和增益，记录版本、`DEV_CFG`、返回点数、时间戳及文件大小。有有效 I/Q 数据后再逐路核对物理接口与掩码的映射。
4. 在测试链路上分别验证多路发送、同步收发和外部参考/PPS。记录收发事件计数、时间戳连续性以及跨通道已知信号的对齐结果。

手册中的频率、采样率和增益是测试输入。Rev1.1 与这份 SDK 的驱动、固件和传输组合仍待联机确认。
